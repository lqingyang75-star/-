实时选股助手

实时行情 + 多策略评分：智能选股、策略对比、个股分析。

选股结果

尚未查询，点击「实时选股」获取结果。

自选股

点击自选代码将其填入输入框并立即查询，可删除单只。

系统扫描内置股票池（30 只主流 A 股），实时拉取行情并按策略评分排名。

选股榜单

点击「一键选股」，从股票池中筛出评分靠前的股票。

同一批股票分别按 价值型 / 成长型 / 均衡型 打分，看它更适合哪种投资风格。

策略对比

输入股票代码后点击「开始对比」。

输出估值、盈利、风险提示与评级建议的个股分析报告。

分析报告

输入一只股票代码，生成分析报告。
